# GOLD-X 2.0 — نظام توقع الذهب

تطبيق Streamlit عربي بواجهة RTL يقرأ بيانات الذهب والمؤشرات المرتبطة من Yahoo Finance، ثم يمررها عبر نموذج متعدد الطبقات يجمع بين العوامل الاقتصادية والتدفقات ومخاطر الذكاء الاصطناعي. يعرض التطبيق حالة السوق، السعر المتوقع، درجة الثقة، رادار البيع القسري، وتحليلاً مرئياً للعوامل.

## ما الجديد في الواجهة

- تجربة مجانية للزائر دون تسجيل دخول.
- قسم تعريفي يشرح قيمة المنصة قبل عرض التحليل.
- اختيار اهتمام يُستخدم داخل الجلسة فقط، ولا يُرسل أو يُخزن.
- نموذج اهتمام بالنشرة مع موافقة واضحة؛ لا يتم حفظ البريد في هذه النسخة لأن مزود النشرة لم يُربط بعد.
- عرض تمهيدي لخطة Premium ومساحات مهيأة للرعاية والشراكات دون تفعيل دفع أو إعلانات فعلية.
- تنبيه واضح بأن النتائج تحليلية وليست نصيحة استثمارية.

> لتحقيق جمع بريد فعلي أو إحصاءات زوار دائمة، يجب ربط مزود خارجي أو قاعدة بيانات مع سياسة خصوصية وموافقة مناسبة. لا تدّعي الواجهة الحالية أنها تجمع هذه البيانات.

## التشغيل المحلي

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run app.py
```

ثم افتح العنوان الذي يظهره Streamlit، وغالباً `http://localhost:8501`.

## بنية المشروع

- `app.py`: واجهة Streamlit العربية، التحليل، قسم الجمهور، النشرة التمهيدية، ومساحات النمو.
- `model.py`: نموذج GOLD-X 2.0، حالات السوق والطبقات ورادار البيع القسري.
- `data_fetcher.py`: جلب متعدد المصادر من Yahoo Finance مع دعم Metals-API الاحتياطي، ومعالجة الفشل الجزئي وجودة المصدر.
- `requirements.txt`: الإصدارات المثبتة للتبعيات.
- `.streamlit/config.toml`: الثيم وإعدادات الخادم.

## النشر على Streamlit Community Cloud

1. أنشئ مستودعاً عاماً أو خاصاً على GitHub وارفع جميع ملفات المشروع، مع الحفاظ على المجلد `.streamlit`.
2. افتح `https://share.streamlit.io` وسجّل الدخول بحساب GitHub.
3. اختر **New app** ثم حدّد المستودع والفرع `main` والملف الرئيسي `app.py`.
4. اضغط **Deploy** وانتظر تثبيت الحزم وبدء التطبيق. لا يحتاج المشروع حالياً إلى أسرار أو مفاتيح API؛ مصدر البيانات هو Yahoo Finance.
5. بعد نجاح النشر انسخ رابط التطبيق من لوحة Streamlit Cloud. إذا ظهرت مشكلة مؤقتة في بيانات السوق، استخدم زر **تحديث البيانات** أو راجع سجلات التطبيق. يعرض التطبيق حالة المصدر: مباشرة، جزئية، أو احتياطية.

## الأسرار والخصوصية

لا تضع كلمات المرور أو مفاتيح API في GitHub. مصدر Metals-API اختياري؛ عند تفعيله أضف `METALS_API_KEY` من **Manage app → Settings → Secrets** في Streamlit Cloud، ولا ترفع `.streamlit/secrets.toml` إلى المستودع. إذا تعطل Yahoo Finance، يحاول التطبيق استخدام Metals-API لسعر الذهب، بينما يستخدم قيماً افتراضية معلنة للمؤشرات الثانوية غير المتاحة.

## النشر على Railway

يمكن تشغيل المشروع على Railway بإضافة مستودع GitHub ثم ضبط أمر البناء:

```bash
pip install -r requirements.txt
```

وأمر التشغيل:

```bash
streamlit run app.py --server.address 0.0.0.0 --server.port $PORT
```

## تنبيه مهم

GOLD-X 2.0 أداة مساعدة للتفكير والتحليل وليست نصيحة استثمارية أو توصية شراء وبيع. تعتمد النتائج على بيانات مزود خارجي وافتراضات يدوية، وقد تفشل عملية الجلب أو تتأخر البيانات. تحقّق دائماً من مصادر مستقلة واستشر مختصاً مالياً قبل اتخاذ أي قرار.
