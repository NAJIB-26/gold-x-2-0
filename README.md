 Yahoo Finance ونموذج متعدد الطبقات.
# GOLD-X 2.0

تطبيق ويب عربي لتحليل وتوقع اتجاه أسعار الذهب باستخدام Python وStreamlit.

يجلب التطبيق بيانات السوق من Yahoo Finance، ويحلل العوامل الاقتصادية والتدفقات السوقية ومخاطر الذكاء الاصطناعي، ثم يعرض:

- السعر الحالي والمتوقع.
- درجة الثقة.
- حالة السوق.
- رادار البيع القسري.
- الإنذارات المبكرة.
- مخططًا تفاعليًا للعوامل المؤثرة.
- واجهة عربية تدعم اتجاه RTL.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
